# 🚀 AbsoluteSite
### *Your essential shortcuts. Your favorite sites. Instantly.*

[![Version](https://img.shields.io/badge/Version-2026.2-green.svg)](#)
[![License](https://img.shields.io/badge/License-GPL--v3-blue.svg)](#)

**AbsoluteSite** is designed for efficiency. Stop wasting time navigating through bookmarks or typing long URLs. It provides a centralized, high-speed management system to organize and launch your most important web destinations with a single keystroke.

## ✨ Powerful Features
* **🎯 Smart URL Capture:** Instantly grab the URL of the page you are currently browsing without selecting or copying.
* **📂 Categorized Organization:** Group your sites into custom categories (e.g., Work, Social, News) for a clutter-free experience.
* **⚡ Contextual Shortcuts:** A single hotkey performs different actions based on tap speed—management or instant adding.
* **🔍 Dynamic Site List:** Search and filter through your collection with an intuitive, screen-reader optimized interface.
* **📝 Auto-Naming:** Intelligent logic that automatically suggests a clear display name for any URL you add.

---

## 🛠 How to Use
1.  **To Manage or Open Sites:** Press `Alt+Backspace` once. The Site Manager will appear. Browse categories and launch your chosen site by pressing **Enter**.
2.  **To Add a New Site:** While browsing a website you like, press `Alt+Backspace` twice quickly (**Double Tap**).
3.  **Refining Your Entry:**
    * The **Add Site** dialog will appear with the URL already filled in.
    * Choose or create a **Category**.
    * Adjust the **Display Name** if desired.
    * Press **Save** to store it forever.

## ⌨️ Hot Keys Summary
| Gesture | Action | Result |
| :--- | :--- | :--- |
| `Alt+Backspace` (Single) | **Open Manager** | Browse and open your saved sites |
| `Alt+Backspace` (Double) | **Add Current Site** | Instantly capture and save the current URL |
| `Delete` (In List) | **Delete Site** | Remove the selected site from your list |
| `Escape` | **Close** | Exit any AbsoluteSite dialog quickly |
