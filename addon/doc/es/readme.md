# 🚀 AbsoluteSite
### *Tus atajos esenciales. Tus sitios favoritos. Al instante.*

**AbsoluteSite** está diseñado para la eficiencia. Deja de perder tiempo navegando por marcadores o escribiendo URLs largas.

## ✨ Funciones potentes
* **🎯 Captura inteligente de URL:** Captura al instante la URL de la página sin seleccionar ni copiar.
* **📂 Organización categorizada:** Agrupa tus sitios en categorías personalizadas.
* **⚡ Atajos contextuales:** Una sola tecla realiza diferentes acciones según la velocidad de pulsación.

## 🛠 Cómo utilizar
1.  **Gestionar:** Pulsa `Alt+Retroceso` una vez para abrir el Gestor.
2.  **Añadir:** Pulsa `Alt+Retroceso` dos veces rápidamente para capturar el sitio actual.
3.  **Guardar:** Ajusta la categoría y el nombre, luego pulsa Guardar.
