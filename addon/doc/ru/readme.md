# 🚀 AbsoluteSite
### *Ваши важные ссылки. Любимые сайты. Мгновенно.*

**AbsoluteSite** создан для эффективности. Хватит тратить время на поиск в закладках или ввод длинных URL.

## ✨ Мощные функции
* **🎯 Умный захват URL:** Мгновенно копирует адрес страницы без выделения.
* **📂 Категории для порядка:** Группируйте сайты по папкам для удобства.
* **⚡ Контекстные клавиши:** Одно нажатие — менеджер, двойное — добавление.

## 🛠 Как использовать
1.  **Управление:** Нажмите `Alt+Backspace` один раз для открытия менеджера.
2.  **Добавление:** Нажмите `Alt+Backspace` дважды быстро, чтобы сохранить текущий сайт.
3.  **Сохранение:** Выберите категорию и имя в появившемся окне.
