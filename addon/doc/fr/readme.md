# 🚀 AbsoluteSite
### *Vos raccourcis essentiels. Vos sites préférés. Instantanément.*

**AbsoluteSite** est conçu pour l'efficacité. Ne perdez plus de temps à naviguer dans vos favoris ou à taper de longues URL.

## ✨ Fonctionnalités puissantes
* **🎯 Capture intelligente d'URL :** Saisissez l'URL de la page sans avoir à la sélectionner.
* **📂 Organisation par catégories :** Regroupez vos sites dans des catégories personnalisées.
* **⚡ Raccourcis contextuels :** Une seule touche pour gérer ou ajouter selon la vitesse de frappe.

## 🛠 Comment l'utiliser
1.  **Gérer :** Appuyez une fois sur `Alt+Retour arrière` pour ouvrir le gestionnaire.
2.  **Ajouter :** Appuyez deux fois rapidement sur `Alt+Retour arrière` pour capturer l'URL.
3.  **Enregistrer :** Choisissez la catégorie et validez.
