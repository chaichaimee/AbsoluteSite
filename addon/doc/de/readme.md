# 🚀 AbsoluteSite
### *Ihre wichtigsten Kurzbefehle. Ihre Lieblingsseiten. Sofort.*

**AbsoluteSite** ist auf Effizienz getrimmt. Verschwenden Sie keine Zeit mehr mit dem Suchen in Lesezeichen oder dem Tippen langer URLs.

## ✨ Leistungsstarke Funktionen
* **🎯 Intelligente URL-Erfassung:** Erfassen Sie sofort die URL der Seite, ohne sie markieren zu müssen.
* **📂 Kategorisierte Organisation:** Gruppieren Sie Ihre Seiten in benutzerdefinierten Kategorien.
* **⚡ Kontextbezogene Kurzbefehle:** Ein einziger Hotkey führt je nach Tippgeschwindigkeit verschiedene Aktionen aus.

## 🛠 Bedienungsanleitung
1.  **Verwalten:** Drücken Sie einmal `Alt+Rücktaste`, um den Manager zu öffnen.
2.  **Hinzufügen:** Drücken Sie zweimal schnell `Alt+Rücktaste`, um die aktuelle Seite zu speichern.
3.  **Speichern:** Wählen Sie eine Kategorie und einen Namen im erscheinenden Dialog.

## ⌨️ Tastenkombinationen
| Geste | Aktion |
| :--- | :--- |
| `Alt+Rücktaste` (Einfach) | Manager öffnen |
| `Alt+Rücktaste` (Doppelt) | Aktuelle Seite hinzufügen |
